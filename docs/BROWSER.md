# Murzila Browser

Обычный браузер: вкладки, адресная строка, поиск, история, закладки, настройки и 50 возможностей.

## Возможности

- Любой поиск или ввод адреса открывает **новую вкладку**, текущая не перезаписывается.
- Выбор поисковой системы в настройках: DuckDuckGo, Google, Bing, Yandex, Brave, Ecosia.
- Экономичный режим и аппаратное ускорение — для слабых машин и 4K.
- F11 — полноэкранный режим, Ctrl +/- — масштаб.
- Кнопка «50» — список возможностей, шестерёнка — настройки.
- Переводчик, голосовой перевод и «живые голоса» в контекстном меню вкладки.
- Обновления проверяются в приложении, скачивание MSI без локального сервера.
- Аккаунт через сайт: Murzila, GitHub, Google.
- История и закладки хранятся локально, в JSON.

## Сборка

```powershell
dotnet build src/MurzilaBrowser/MurzilaBrowser.App/MurzilaBrowser.App.csproj -c Release
.\src\MurzilaBrowser\MurzilaBrowser.App\bin\Release\net10.0-windows\win-x64\MurzilaBrowser.exe
```

Текущая сборка требует Windows 10/11. Для Windows 7 нужна отдельная legacy-ветка на более старом наборе инструментов; это отдельный этап.
