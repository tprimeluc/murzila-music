# План Murzila Music — декабрь 2026

## Сделано 24.11.2026
- Нативное приложение без WebView; 2FA при входе в приложении.
- Сессия: cookie теперь ставится после входа по коду и после регистрации.
- Настройки: чтение свежего файла перед открытием + защита от второй копии приложения.
- Бот: мгновенный ответ «Ищу трек…», иконка, источник, меню выбора трека.
- Монохромная тема, свой курсор, анимация иконки, пасхалка в подвале (5 секунд наведения).

## Сделано 27.11.2026
- Пометки `Explicit` / `18+`: колонки в БД, авто-определение по названию/тексту, ручная установка, бейджи в списке треков.
- Подтверждение артиста: кнопки «крупный/не крупный», код `murzila-verify-XXXXX`, пороги 1000 слушателей и 500 подписчиков, значок `Подтверждено Murzila ✓`.
- **Murzila Kassa**: внутренний баланс, ручное пополнение, подписки basic/pro/ultra, страница в плеере.
- **Быстрый поиск текста**: LrcLib + Genius + Musixmatch + lyrics.ovh опрашиваются параллельно, в ответе время каждого провайдера в мс; поле поиска в караоке.
- **Murzila FileSharing**: загрузка своего файла до 200 МБ, публичная ссылка `/s/ID`, раздача по URL, список и удаление, страница `/files`.
- Из плеера убраны визуализатор и кнопки под ним.
- Сжатие ответов (Brotli/Gzip) и кэш для статики; HTML всегда без кэша.
- Все сайты одного хоста: `/player`, `/files`, `/api/token`, `/download`, домен с `filesharing` → Filesharing, `mursik-corp` → сайт компании.
