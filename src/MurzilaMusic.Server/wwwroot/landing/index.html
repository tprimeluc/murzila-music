Murzila Music API

Лёгкий API: создаёшь приложение, получаешь ключ, меняешь его на токен и читаешь только свою библиотеку. Как у больших сервисов — только без чужих каталогов.

  • API-ключ на аккаунт
  • Bearer-токен на 30 дней

Как это работает

Четыре шага до своей музыки

Без импорта чужих каталогов. Всё, что появляется в библиотеке, выбрал ты сам.

1

Аккаунт

Регистрация по почте в приложении или прямо на сайте. Один аккаунт на все домены.

2

Свои файлы

Добавляешь треки из проводника. Приложение читает теги и обложки с твоего устройства.

3

Синхронизация

Загруженное хранится в твоём облаке на нашем сервере и доступно только по твоему токену.

4

Слушаешь где угодно

Браузер, приложение или свой плеер через API — с перемоткой и обложками.

Для разработчиков

API в три строки

Никакой регистрации приложения вручную: открываешь /api/token, входишь, создаёшь приложение и сразу получаешь ключ. Ключ меняется на токен, токен живёт 30 дней.
