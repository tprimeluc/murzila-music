    Как пользоваться

    # 1. Получить токен по API-ключу
curl -X POST http://localhost:6001/api/token \
  -H "Content-Type: application/json" \
  -d '{"apiKey":"ВАШ_КЛЮЧ"}'

# 2. Список своих треков
curl http://localhost:6001/api/music/library \
  -H "Authorization: Bearer ВАШ_ТОКЕН"

# 3. Стрим трека (перемотка работает через Range)
curl http://localhost:6001/api/music/files/ID_ТРЕКА \
  -H "Authorization: Bearer ВАШ_ТОКЕН"

# 4. Обложка
curl http://localhost:6001/api/music/cover/ID_ТРЕКА \
  -H "Authorization: Bearer ВАШ_ТОКЕН"

    Токен можно передавать и как ?token= — так работают HTML-плееры и <audio>, которые не умеют заголовки.
