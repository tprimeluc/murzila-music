Murzila Music 3.6

Персональный веб-плеер и десктоп-приложение MursikT7 Corporation: только твои треки, караоке с пословной подсветкой, эквалайзер, API, 2FA и безопасный ботовый стрим. Никаких чужих каталогов.

Слушать сейчас API и токены

Своя библиотека

До 5000 треков. Обложки, тексты, альбомы и заметки — всё в одном месте.

Караоке

Синхронная подсветка строк и слов в такт вокалу. Клик по строке — перемотка.

Эквалайзер

10 полос с пресетами. Настройки сохраняются в браузере.

Безопасный вход

Почта, GitHub, 2FA. Гостевой режим — 5 часов без регистрации.

Свой API

Ключи и Bearer-токены, стрим с Range, отдельный доступ только для ботов.

Только свои треки

Чужие композиции доступны лишь если артист сам разрешил прослушивание.
